# One-Minute Survival

A browser-based HTML5 survival game where you fight off waves of enemies for a full 60 seconds.

## Features
- Auto-firing combat
- Random upgrades after each level-up
- High-score tracking with local storage
- Keyboard and mobile joystick controls
- Arcade HUD and end-of-run summaries

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server.

## Controls
- Move: WASD / Arrow keys
- Pause: Escape
- Mobile: On-screen joystick
